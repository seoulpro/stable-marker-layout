# Code of Conduct

## Purpose

This project welcomes contributors of every background. Participation should
be a harassment-free experience for everyone.

## Expected behavior

- Be respectful and assume good faith.
- Critique ideas and implementations, not people.
- Give and accept technical feedback constructively.
- Keep discussions focused on the project and its use cases.
- Protect private and sensitive information.

## Unacceptable behavior

- Harassment, insults, threats, or discriminatory language.
- Personal or political attacks.
- Publishing another person's private information without permission.
- Sustained disruption of project discussions or reviews.

## Scope

This code applies in issues, pull requests, and other project spaces, as well
as when representing the project in public.

## Reporting and enforcement

Ask the maintainers for a private reporting channel without publishing
sensitive details. Security vulnerabilities should follow
[SECURITY.md](./SECURITY.md).

Maintainers may clarify these standards and take proportionate action,
including editing or removing contributions, warnings, or access restrictions.
